**Button Vault** is a premium, curated gallery of 50 handcrafted, interactive UI buttons designed for modern web applications. Built entirely with raw web performance in mind, it serves as a playground and copy-paste resource repository for frontend developers and UI/UX designers looking to elevate micro-interactions.

🚀 **Live Demo:** [button-vault.awaiss.tech](https://button-vault.awaiss.tech/)

---

## 🎨 Feature Highlights

* **10 Core Design Categories:** From production-ready sleek minimal styling to heavy-compute advanced canvas animations.
* **Button Lab v2.0 Sandbox:** A live simulation environment to test buttons against various theme tokens (`BG`, `Card`, `Accent`, `Light`, `Dark`, `Gradient`) ensuring strict AA/AAA contrast and accessibility compliance.
* **Live Customizer Panel:** Adjust visual controls natively (padding, border-radius, font-weights, spatial text tracking, complex box-shadow layers) and watch the underlying CSS compile instantly.
* **Instant Multi-Format Export:** Copy raw component logic or export full assets straight into Web Bundles (`.html`), clean Data Objects (`.json`), or functional configuration text strings (`.txt`).
* **Community Contribution Pipeline:** Integrated publishing modal allowing external creators to structure and submit custom-built interactions directly into the public vault ledger.

## 🛠️ Technology Stack

* **Frontend Engine:** HTML5, Modern CSS3 (Variables, Pseudo-elements, CSS Grid & Flexbox), Vanilla JavaScript (ES6+ Context state parsing).
* **Sandbox Environment:** Custom-built live canvas renderer isolating modular scoped layouts without document runtime bleed.
* **Theming / UI System:** Highly responsive utility-driven presentation architecture optimized for cross-browser matrix consistency.
